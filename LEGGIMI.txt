USARE IL CODICE
Per sviluppo locale servono Node.js 24 e npm 11. Dalla cartella sorgenti:
  npm ci
  npm run web
Per il pannello amministrativo, in un altro terminale:
  npm run admin
Le istruzioni complete, incluse Supabase e le verifiche, sono in
sorgenti/README.md e sorgenti/supabase/README.md.

USARE LA DEMO WEB ESPORTATA
La cartella demo-web va servita da un server HTTP sotto il percorso
/GAIA_NIDO/, con 404.html come fallback per le pagine interne e .nojekyll
preservato. Non è sufficiente aprire index.html con doppio clic.
Per ricostruirla dalla cartella sorgenti:
  NIDO_WEB_BASE_PATH=/GAIA_NIDO EXPO_OFFLINE=1 npm run build:web
Il risultato sarà in apps/mobile/dist-web.

Questo archivio contiene codice ed esportazione web, non un APK/IPA firmato.
In assenza di configurazione Supabase l'app usa la modalità demo. Le istruzioni
sulla configurazione del servizio reale si trovano nei README e nei due
.env.example. Dipendenze installate, cache, cronologia Git e credenziali private
non fanno parte del pacchetto.
